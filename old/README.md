safestr: Dynamic String Manipulation LibraryVideo Demo:  <URL_DE_TU_VIDEO_YOUTUBE_O_OTRO>Description:safestr is a lightweight, safe, and dynamic string manipulation library for the C programming language. The primary problem it solves is the manual and often error-prone management of static character arrays (buffers) and null-terminated strings in standard C. Buffer overflows, memory leaks, and out-of-bounds access are common pitfalls when processing data of unpredictable sizes, such as user inputs, network payloads, or file parsing.This library encapsulates string data within a custom SafeString structure, which automatically handles memory allocation, reallocation (dynamic growth), and boundaries. By abstracting away the manual malloc, realloc, and free operations during string mutations, safestr provides a safer and more developer-friendly interface reminiscent of higher-level languages.  Internal ArchitectureThe library revolves around a central data structure:  Ctypedef struct {
    char*  data;
    size_t length;
    size_t capacity;
} SafeString;
data: A pointer to the dynamically allocated heap memory storing the string characters.  length: The current number of characters in the string (excluding the null terminator).  capacity: The total allocated size in memory.  When an operation requires more space than the current capacity, an internal static function ss_grow automatically scales the allocation by a factor of 2. This exponential growth strategy ensures amortized $O(1)$ time complexity for repetitive append operations.  API ReferenceThe library exposes the following public API:  SafeString ss_new(void)

Concatenates a standard C string to the end of the SafeString. It dynamically resizes the internal buffer if the existing capacity is insufficient.  bool ss_insert(SafeString* s, size_t pos, const char* text)
Inserts a standard C string at a specific index within the SafeString. It shifts existing characters to the right and handles memory resizing automatically.  bool ss_substring(const SafeString* s, size_t inicio, size_t fin, SafeString* out)

Testing and ValidationThe project includes an aggressive testing suite built to validate edge cases. The test files (test_safestr.c and test2.c) assert expected behaviors against out-of-bounds index requests, null pointer injections, and extreme memory stress (simulating thousands of rapid reallocations). The test environment uses AddressSanitizer to rigorously prove the absence of memory leaks and invalid memory accesses.
